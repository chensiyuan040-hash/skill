## 2. 一句话结构

用 transcript 驱动剪辑：先转写口播，再按文本删静音、删口误、重定时，生成 EDL 让人审核，最后才渲染画面、字幕、B-roll 和音效。

## 3. 时间轴

仓库提供三个入口工作流，底层共用同一条“转写 → 剪切 → 包装 → preflight”流水线。

| 入口 / 阶段 | 产出 | 要点 |
|---|---|---|
| `edit-video` | 长视频剪辑 | 面向课程、访谈和完整口播 |
| `short-form-edit` | 竖屏短视频 | 从长转写里挑高密度片段重排 |
| `motion-showreel` | 动效 showreel | 用 406 张动效卡做节奏剪辑 |
| 1 转写 | transcript + 词级时间戳 | 转写质量决定后面所有切点 |
| 2 剪切 | 去静音、去口误、重定时 | 先按文本切，不靠拖时间线听 |
| 3 字幕 | caption 与源文本映射 | 字幕跟随剪切后的时间码 |
| 4 B-roll | 辅助画面 | 只在口播需要举例或遮挡时插入 |
| 5 音效 | SFX 与音乐 | 服务切点和强调，不填满空隙 |
| 6 preflight | 素材、字幕、场景覆盖检查 | 检查通过后才进入最终渲染 |

口播剪辑的时间轴本质上是“文本时间轴”：切点先落在词和句子上，再映射回音频采样位置。

## 4. 视觉语法

- HyperFrames 模板提供字幕、标题、B-roll 框架和转场骨架，视觉风格可按项目替换。
- 406 张动效卡按用途分类，用于标题、强调、转场和背景运动。
- 保留 12 个教学项目，可当结构参考；README 说明原始项目仍在 `video-projects/`。
- 画面主体是口播人物或屏幕内容，动效卡只做包装，不喧宾夺主。
- 模板化程度高，适合批量口播；需要强品牌感时要重做配色和字体。
- 406 张卡不需要全用，一条片通常只挑 3–5 张。

## 5. 动效与转场

- 剪切点由 transcript 的删改驱动，画面跳切直接跟随音频切点。
- 重定时会改变口播速度，动效和字幕必须按新的时间码重新计算。
- beat-sync 校验用于确认动效卡入场和音乐节拍对齐。
- 动效卡以入场、强调、转场三类为主，避免长时间循环动画。
- B-roll 插入遵循“说到才出现”，不提前泄露信息。
- 转场优先硬切和遮挡，长溶解会拖慢口播节奏。

## 6. 字幕与声音

- caption 与 source mapping 记录每条字幕来自哪段原始转写，方便回溯和纠错。
- 字幕时间跟随剪切后的音频，不沿用原始时间码。
- 删口误后要重新断句，避免字幕把半句话留在屏幕上。
- audio review 检查响度、静音段和削波；去静音后尤其要复查段落衔接。
- 音乐和 SFX 在剪切定稿后再铺，避免每次改切点都重排音效。
- 中文转写要额外检查同音字、数字和人名，不能直接信任自动结果。

## 7. 可执行配方

1. **transcript 先切**
   - 先完整转写，再在文本里标出静音、口误、重复和离题段。
   - 按句子或语义块删除，不按固定秒数硬切。
   - 切完先听一遍音频接缝，确认没有吞字和爆音。
2. **EDL 审核再渲染**
   - 把剪切决策导出成 EDL，逐条核对入点、出点和保留理由。
   - 让人工审核 EDL，而不是直接看渲染成片才发现剪错。
   - EDL 定稿后才生成字幕、B-roll 和音效，减少连锁返工。
3. **preflight 检查素材 / caption / 场景覆盖**
   - 检查所有素材路径可读、分辨率和帧率一致。
   - 检查每条 caption 有时间码、无空行、无溢出。
   - 检查 storyboard 里每个场景都有对应素材，避免渲染到一半缺镜头。

## 8. 失败模式

- **品牌素材与许可边界**：主体 MIT 且教学套件另给使用许可，但 AIS 品牌素材被明确排除，HyperFrames 组件仍按 Apache-2.0。解决：保留版权与许可声明，替换品牌素材，商用前逐层复核。
- **需要真人复核**：自动转写和自动剪切会把专有名词、反讽和语气词切错。解决：EDL 必须人工过一遍。
- **转写可能需付费 key**：部分转写路径依赖第三方服务。解决：提前确认成本和额度，准备本地转写备选。
- **过度依赖 406 张卡**：每条片都套同一批动效，很快模板化。解决：固定 3–5 张常用卡，其余按题材替换。
- **重定时破坏音画同步**：变速后字幕和动效仍按旧时间码。解决：所有下游元素从剪切后的时间轴重新生成。
- **去静音去过头**：句子之间没有呼吸，听感很赶。解决：保留 100–200ms 的自然停顿，按语义而非波形删除。

## 9. 关键帧与适用场景

- 远程案例，无本地关键帧；需要时先拉取仓库，用一段 1 分钟口播跑通转写和剪切。
- 重点看：`edit-video` 与 `short-form-edit` 的切点策略、EDL 的字段结构、preflight 的检查清单。
- 适合：口播剪辑、课程录制、访谈重剪、需要把长素材快速压成短片的项目。
- 不适合：没有口播的纯动效片、需要强叙事表演的片子、许可要求严格的商业交付。
- 借用建议：主卡借“transcript 先切 + EDL 审核 + preflight”的流程；辅卡最多借一类动效卡的用法，不要把 406 张卡当成风格库。
