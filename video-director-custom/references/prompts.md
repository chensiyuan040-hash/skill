# 提示词模板

这些模板来自对参考教程的拆解，重点不是“让 AI 写代码”，而是**先把质量标准写死**。

## 1. 质量门槛（放在每次生成的开头）

```text
You are the director, motion designer, engineer and sound designer
of ONE 10-second motion-design film.
The goal is the most classic yet most stunning form of this style —
award-shortlist / high-end commercial quality.
A clean, template-looking result is a fail.
```

中文补充：

```text
目标是获奖短片/高端商业定制的完成度。
一个“干净的模板感”结果视为失败。
不要用现成 UI 套壳，不要用默认缓动，不要用无意义的粒子堆砌。
每一个元素都必须为这句文案服务。
```

## 2. 一句话 brief

```text
用 <时长> 秒、<画幅>，讲清楚“<一句话主题>”。
目标观众是 <谁>。
看完后他们应该记住 <一个点>。
素材：<有/没有；有什么>。
```

写完后自查：一个没看过背景的人，能不能只看这句话就知道片子要讲什么？

## 3. 风格适配

```text
使用风格模板 <编号 + 名称>（见 style-library.md）。
保留这个风格的：<3 个视觉要素>、<2 个动效词汇>。
替换成我的内容：<文案/数据/产品>。
不要改变画幅、色盘和字体系统。
先给我 4 张关键帧，不要直接渲染整片。
```

## 4. 10 秒样片

```text
先做 10 秒样片，只包含：
1. 开场 2 秒（建立风格）
2. 主体 5 秒（核心信息）
3. 收尾 3 秒（落版）
要求：每一帧都是时间 t 的纯函数，没有 CSS transition，没有随机数。
输出 MP4 + 4 张关键帧。
```

## 5. Critic subagent

```text
你是这条片子的独立评审，不是作者。
读 <critic.md 路径>，严格按 1–10 评分卡评审。

Brief：<一句话>
风格：<编号 + 名称>
画幅/时长/fps：<...>

输出：
1. 4 张关键帧：<路径>
2. 10 秒样片：<路径>
3. contact sheet：<路径>

只根据屏幕结果打分，不要替作者解释意图。
给总分、五项分、每项证据、Top 3 fixes。
通过线：总分 ≥ 8，且没有单项 < 7。
```

## 6. 迭代

```text
Critic 给了以下 Top 3 fixes：
1. ...
2. ...
3. ...

只改这三项，不要顺手改别的。
改完重新渲染 10 秒样片，并说明每一项具体改了什么（文件/行号/参数）。
```

## 7. “不靠 skill”压力测试（可选）

来自参考教程的实验：让模型完全从零发挥，看看它的上限。

```text
帮我制作一个动画，主题是 <...>；包括音效和音乐；
你可以使用任何你觉得合适的工具和技术，做出最好最惊艳的效果。
不要使用已有的 skill，不要参考以前做过的视频或者文案。
```

这个模式适合探索风格，不适合稳定交付。探索出好结果后，把它固化成 `style-library.md` 里的模板。

## 8. 先定评分标准

```text
在写任何代码之前，先为这个风格拟定一份 1–10 分的评估标准。
5 分 = 合格的学生作业
6 分 = 模板 / 剪映水平
7 分 = 扎实的专业水准
8 分 = 获奖短片 / 高端商业定制
9 分 = 例外级
10 分 = 大师级
写清楚每一档在这个风格里具体看什么。
```

先定标准，再生成，能显著减少“看起来很努力但不好看”的结果。

## 9. 参考片拆解

```text
读 <参考片路径>，用 teardown_reference.py 抽 12 帧和场景切点。
按 references/cases/ 的 9 段格式写一张案例卡：
元信息 / 一句话结构 / 时间轴 / 视觉语法 / 动效与转场 /
字幕与声音 / 3 条可执行配方 / 失败模式 / 关键帧与适用场景。
时间轴标注“近似”，不要编造精确到帧的时间。
```

## 10. 三选一样片

```text
基于案例卡 <卡名>，做 3 个 3 秒样片，分别偏重：
A. 结构忠实（照搬节奏）
B. 视觉忠实（照搬色盘/材质）
C. 节奏变体（更快/更慢）
每个样片只验证一个维度；输出 3 个 MP4 + 3 张关键帧，让我选一个再做 10 秒。
```

## 11. 口播场景映射

```text
读 <TRANSCRIPT.md / transcript.json>，把每个句子映射到画面：
- 句子/时间
- 画面主体
- 动作/表情
- 字幕位置
- 音效/转场
先给我表格，不要写代码；确认后再做 4 张关键帧。
```

## 12. 交付验收

```text
跑 verify_delivery.py：
- 报告分辨率、fps、帧数、时长、音频流、响度、TP、静音、静止、首尾帧。
- 把 PASS/WARNING/FAIL 写进 docs/SCORECARD.md。
- 响度 WARNING 不要自动重编码；说明是否保留原声。
- 输出 contact sheet。
```
