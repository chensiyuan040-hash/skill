## 2. 一句话结构

三幕式反转：先用“33 票 / 像不像侠”建立前提，再用“进化 / 海豚侠对比”升级预期，最后用“米粒龙控制吃吼霸的反转 + 肌肉 / 攻击力 160 处刑”完成笑点。

## 3. 时间轴

| 区间（近似） | 内容 | 作用 |
|---|---|---|
| 0–10s | 前提：“33 票 / 像不像侠” | 抛出判断标准 |
| 10–30s | 进化、海豚侠对比 | 建立比较关系 |
| 30–45s | 米粒龙控制吃吼霸的反转 | 打破预期 |
| 45–66s | 肌肉 / 攻击力 160 / 结尾卡 | 处刑式收束 |

结构上每一幕都围绕一个“比较”推进：像不像、进化前后、谁控制谁、数值高低。比较对象必须在画面中同时可见。

## 4. 视觉语法

- 384×216 逻辑画布，放大 5 倍到 1920×1080，保持整数倍缩放。
- AG 角色为 64×97，四表情；音箱蟀 67×73，44 帧动画。
- 海豚侠、米粒龙、吃吼霸使用 64×64 GBA 规格。
- 色盘控制在 16–24 色，同一场景不引入新色系。
- 像素字与 CSS 卡片混排：像素字承担角色台词，CSS 卡片承担数据与标签。
- 关键对象按设定尺寸锁定比例，不因构图随意缩放。

## 5. 动效与转场

- 44 帧精灵动画承担主要动作段落，帧率与 24fps 时间轴对齐。
- 静态精灵加 1px bob，避免角色像贴纸。
- 三表情切换用于反应镜头，切换点对齐台词重音。
- 冲击帧、白闪用于反转和“处刑”时刻。
- 柱状图生长用于攻击力等数值比较。
- 结尾卡淡入，给笑点一个明确的落点。

## 6. 字幕与声音

- 原声 48k，无背景音乐；节奏完全由原声和词级字幕驱动。
- 词级字幕轴控制切点，切点误差控制在 0.01–0.07s。
- 字幕与精灵反应绑定：先听到词，再看到表情或动作。
- 响度 -17.7 LUFS、TP -3.0 dBFS，适合平台播放且不明显削波。
- 没有音乐时，静音和停顿本身成为节奏工具，不要用 SFX 填满每个空隙。

## 7. 可执行配方

1. **暂停 3 秒必须能认出角色**
   - 任取一帧暂停，检查主角轮廓、配色和比例是否可辨。
   - 如果认不出，优先修描边和色盘，而不是加特效。
   - 角色同框时保证至少一个完整轮廓不被遮挡。
2. **静态精灵加 2 帧 idle**
   - 为每个主要精灵准备 2 帧轻微起伏或眨眼。
   - 循环周期与 24fps 对齐，避免抖动。
   - idle 幅度控制在 1px，不要破坏像素网格。
3. **比例和标签指向必须正确**
   - 大鱼必须比小鱼大，缩放前先核对设定尺寸。
   - 标签必须贴在对应对象上，不能悬空。
   - 比较类画面同时显示对象、标签和数值，三者不可分离。

## 8. 失败模式

- **28s 吃吼霸 scale 0.35，比米粒龙还小**：体量关系直接违背设定，笑点变成错误。解决：按设定尺寸锁定比例。
- **TATSUGIRI 标签悬空**：标签没有贴住对象，观众不知道在说谁。解决：标签锚点绑定对象包围盒。
- **三只精灵静态**：画面像素材陈列。解决：至少加 2 帧 idle 或表情切换。
- **像素方言混用**：不同规格、不同色盘的精灵同框。解决：统一逻辑画布和色盘后再合成。
- **CSS 字卡片混入像素画面**：渲染方言不统一。解决：数据卡统一像素字规格，或明确限定 CSS 卡只出现在独立信息层。
